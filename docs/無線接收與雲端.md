# Cam Link 0.2.9 無線接收與雲端

**LUMIX S1 II／S1R II**　在 LUMIX Lab 配對，啟用拍攝後自動傳送並選原始尺寸 JPG。先傳一張，確認完整原圖出現在 Android 檔案選擇器可見的本機資料夾。回到 Cam Link，按「＋ 連接 → Wi-Fi 接收 → 使用品牌 App 的相簿 → LUMIX → 選資料夾並開始」。選擇該來源資料夾，待出現「相簿接收中」再拍。開始前已有的檔案屬於基線。Cam Link 只巡查所選資料夾的直接子檔案，接收所有新 JPG，並在驗證後另存至 DCIM/CAM LINK。品牌 App 仍須按其規定保持傳輸。若原圖只在該 App 私有相簿，需要先匯出到可見資料夾。[Panasonic 無線自動傳相說明](https://av.jpn.support.panasonic.com/support/global/cs/soft/lumix_lab/en/cts/b1.html)

**Sony、Canon、Nikon、Fujifilm**　具備無線 FTP 傳送功能的機身，可將 手機 與相機連到同一個私人 Wi-Fi 網絡，按「＋ 連接 → Wi-Fi 接收 → 相機直接傳送 · FTP → 開啟 FTP 接收」。將手機顯示的 IPv4、連接埠 2121、帳戶 camlink 和本場密碼填入機身。選 FTP、被動模式、JPG 自動傳送。接收器支援 PASV 及 EPSV，使用明文 FTP，僅適合受信任的私人網絡。相機顯示傳送完成後，再於 Cam Link 按「停拍並完成接收」。機身所需配件、韌體和可用模式依型號而定。[Sony](https://helpguide.sony.net/di/ftp/v1/en/contents/TP1000228692.html) · [Canon](https://cam.start.canon/en/C003/manual/html/UG-06_Network_0070.html) · [Nikon](https://onlinemanual.nikonimglib.com/z8/en/ftp_servers_connecting_via_wireless_lan_92.html) · [Fujifilm](https://fujifilm-dsc.com/en/manual/x-h2s_connection/overview_usage/ftp_upload/index.html)

沒有 FTP 選項時，在「使用品牌 App 的相簿」選對應品牌。先確認該型號與品牌 App 能將原尺寸 JPG 傳入手機可選取的本機資料夾；若只支援縮圖，Cam Link 收到的亦只有該尺寸。相機 Wi-Fi 無法上網時，Drive 佇列會等到手機有可用網絡。

| 雲端目的地 | 使用方式 |
|---|---|
| Google Drive | Cam Link 自動上傳並核對。首頁數字屬於畫面所示場次。 |
| 電腦（Windows／Mac） | 配對 Cam Link Receiver 後，下一場的完整 JPG 經區域網絡直接送到所選資料夾。可同時啟用 Google Drive 和 WebDAV。 |
| WebDAV | 在「傳送 → WebDAV」輸入現有 HTTPS 資料夾、帳戶及應用程式密碼。下一場起自動排隊，Android 依網絡和排程送出。檔名含場次及本機識別碼，伺服器須支援條件 PUT 及 GET。回讀 SHA-256 相符才算完成。 |
| OneDrive、Google Photos | 可選 JPG 交給服務 App，亦可在該 App 的裝置資料夾備份設定開啟 CAM LINK。帳戶、保留畫質及流動網絡由該 App 控制。 |
| Dropbox、Box、Flickr | 安裝及登入相應 App 後，從 Cam Link 按服務名稱選取一張或多張 JPG，在該 App 確認目的地與上傳。如該版本不接受 Android 分享，可在其 App 上傳介面選取 CAM LINK。 |

外部 App 的上傳進度在各自 App 查看。WebDAV 設定只儲存在手機，密碼用 Android Keystore 金鑰加密。新雲端服務須以使用者自己的帳戶或伺服器完成首次驗收。

## 手機 傳送至 Windows 或 Mac

1. Windows 開啟 `CamLink-Receiver.exe`。Mac 解壓 `CamLink-Receiver-macOS.zip`，開啟 `Cam Link Receiver.app`。Mac 套件適用 Apple Silicon 及 Intel，未經 Apple 公證。如首次開啟被系統擋下，可在確認檔案來源後從「系統設定 → 私隱與保安」選擇打開。
2. 在電腦選擇收相資料夾（Mac 建議用本機「圖片」）及 手機 能連到的區域網絡 IP。Windows 按「開始接收」。保持接收視窗開啟，並允許本地網絡連線。電腦可接同一路由器的網線；手機 須連到可通往該電腦的 Wi-Fi。連在相機獨立熱點時，如沒有通往電腦的路由，照片會留在佇列。
3. 手機 選「傳送 → 電腦 · Windows / Mac」。輸入接收器顯示的 IPv4 地址及配對碼。手機顯示的 16 位指紋必須與電腦相同，才按「相同，完成配對」。之後會固定核對整個憑證。
4. 開始新一場接收。電腦以含場次的檔名保存原圖，完整寫入及校驗 SHA-256 後才回覆手機。同一張重試會沿用已核對的檔案；同名而內容不同會報錯。點首頁照片查看場次詳情，電腦和 Google Drive 各自顯示已核對張數。
